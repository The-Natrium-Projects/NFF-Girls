JSON METADATA REFERENCE
================================================================================

STANDARD MOB JSON STRUCTURE:
{
  "parent": "root.json",
  "text": "mobname.txt",
  "title": "entity.hmag.mobname",
  "entity_renders": [{
    "entity": "hmag:mobname",
    "x": 92, "y": 102, "page": 0,
    "scale": 1.0,
    "rot_x": 30, "rot_y": 225, "rot_z": 0,
    "follow_cursor": false
  }]
}

KEY INFORMATION:
- "text" = Name of .txt file to display (from en_us/ or zh_cn/)
- "title" = Translation key for mob name (entity.hmag.*)
- "entity_renders" = 3D mob model display parameters
  * x, y = Position on page
  * scale = Display size (0.75-1.0 typical)
  * rot_x, rot_y, rot_z = Rotation angles for 3D rendering

ENTITY NAME PATTERN:
- English: "entity.hmag.mobname" (e.g., entity.hmag.alraune)
- JSON files use: "title": "entity.hmag.alraune"
- Lang files use: "entity.nffgirls.hmag_alraune": "Alraune"
