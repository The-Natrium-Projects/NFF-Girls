To get friendly with an Imp, you must drop the item on the ground. It will pick the item up, watch it for a few seconds
like the Piglin, and consume the item.
<NEWLINE>
The Kobold loves metals, gems and pickaxes. When the progress reaches 70%, it will become neutral.
<NEWLINE>
After getting friendly, you can set its hand items, and it has 2 Bauble slots.
<NEWLINE>
Its main hand accepts only pickaxes. If the pickaxe has a Fortune enchantment, killing mobs will drop more items as if
it had a Looting enchantment.
<NEWLINE>
If it's holding a mineral nugget on the off-hand, it will help locate ores nearby. When finding an ore, it will consume
a nugget, try walking to the ore and generate a lot of green star particles. Now it supports Coal, Copper, Iron, Gold,
Lapis Lazuli, Emerald and Redstone. For Coal, Lapis and Redstone, it needs the mineral itself instead of the nugget. It
locates ores only when in the Follow mode.
<NEWLINE>
The Kobold can be healed with the Apple, Cookie, Pumpkin Pie, Lemon and Lemon Pie. A Golden Apple can fully recover its health.
<NEWLINE>
<NEWLINE>
(*Note: take care using ore locating feature. Now block locating has issues which can cause a waste of metal nuggets.)
