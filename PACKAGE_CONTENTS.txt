DELIMITED FORMAT EXPLANATION
================================================================================

Each content file uses consistent delimiters for parsing:

START MARKER: === filename ===
CONTENT:      [File content with <NEWLINE> for actual newlines]
END MARKER:   Next file's START MARKER or End of File

EXAMPLE FROM EN_US_BOOK_CONTENT.txt:

=== alraune.txt ===
<NEWLINE>
<NEWLINE>
The Alraune is a spirit of nature and plants, found in the Jungle biomes above Y=64.
<NEWLINE>
It can perform 2 types of attack...
[... more content ...]

=== banshee.txt ===
<NEWLINE>
The Banshee is a peculiar spirit...
[... more content ...]

EXTRACTION: Use grep, sed, or awk to isolate content between delimiters

└─ Template: patchouli_books/mob_dictionary/en_us/entries/friending/alraune.json

   - Create: patchouli_books/mob_dictionary/zh_cn/entries/mob/<mobname>.json
   - Create: patchouli_books/mob_dictionary/zh_cn/entries/friending/<mobname>.json

STEP 5: ADD TRANSLATION KEYS
└─ Update: lang/en_us.json and lang/zh_cn.json
   - Add: dict.nffgirls.desc.mob.<mobname>
   - Add: dict.nffgirls.desc.friending.<mobname>
   - Value: Content extracted in STEP 2

STEP 6: TEST & VERIFY
└─ In-game testing:
   - Verify all entries display correctly
   - Verify translations appear properly
   - Verify entity models render correctly
   - Verify navigation works
