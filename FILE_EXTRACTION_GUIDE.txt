3. HOW TO EXTRACT INDIVIDUAL FILES
================================================================================

Each extracted content file uses delimiters to separate files. To extract a specific file:

Unix/Linux Example (extract alraune.txt from EN_US_BOOK_CONTENT.txt):
  sed -n '/^=== alraune.txt ===/,/^=== [a-z_]*\.txt ===/p' EN_US_BOOK_CONTENT.txt | \
    head -n -1 > alraune_extracted.txt

Python Example (extract any file):
  with open('EN_US_BOOK_CONTENT.txt', 'r') as f:
      content = f.read()
      start = content.find('=== alraune.txt ===')
      end = content.find('=== ', start + 1)
      if start != -1 and end != -1:
          file_content = content[start:end].strip()

5. LEGACY JSON FORMAT EXPLANATION
================================================================================

Each mob JSON file in book/mob_dictionary/ follows this structure:

{
  "parent": "root.json",                    // Reference to parent book
  "text": "mobname.txt",                    // Text file to display
  "title": "entity.hmag.mobname",           // Translation key for title
  "linked_page_buttons": [],                // Navigation buttons
  "images": [],                             // Image embeds
  "item_renders": [],                       // Item display info
  "recipes": [],                            // Recipe info
  "tabula_renders": [],                     // Tabula model info
  "entity_renders": [                       // Entity model rendering
    {
      "entity": "hmag:mobname",             // Entity ID
      "x": 92,                              // X position on page
      "y": 102,                             // Y position on page
      "page": 0,                            // Page number
      "scale": 1.0,                         // Display scale
      "rot_x": 30,                          // X rotation (degrees)
      "rot_y": 225,                         // Y rotation (degrees)
      "rot_z": 0,                           // Z rotation (degrees)
      "follow_cursor": false                // Follow mouse movement
    }
  ]
}

Key Points:
  - "text" field references the .txt file containing mob description
  - "title" field uses translation key from lang/*.json
  - "entity_renders" contains positioning and rotation for 3D mob model
  - Entity naming follows format: hmag:mobname (lowercase with underscores)

6. EXISTING PATCHOULI ENTRIES
================================================================================

Found at: patchouli_books/mob_dictionary/en_us/entries/friending/alraune.json

Structure example:
{
  "category": "nffgirls:mobs",
  "name": "hmag:alraune",
  "icon": "nffgirls:textures/book/icon_alraune.png",
  "pages": [
    {
      "type": "patchouli:entity",
      "entity": "hmag:alraune",
      "scale": 0.75
    },
    {
      "type": "patchouli:text",
      "text": "dict.nffgirls.desc.friending.alraune"
    }
  ]
}

This shows:
  - Patchouli uses "type": "patchouli:entity" for entity rendering
  - Patchouli uses "type": "patchouli:text" for text content from lang keys
  - Category organizes entries in the book
  - Icon provides thumbnail for entry
  - Scale controls entity display size

7. MIGRATION STRATEGY
================================================================================

To port from legacy format to Patchouli:

1. For each mob (e.g., alraune):
   
   a. Create entry file:
      patchouli_books/mob_dictionary/en_us/entries/mob/alraune.json
      
      Content should be:
      {
        "category": "nffgirls:mobs",
        "name": "hmag:alraune",
        "icon": "nffgirls:textures/book/icon_alraune.png",
        "pages": [
          {
            "type": "patchouli:entity",
            "entity": "hmag:alraune",
            "scale": 0.75
          },
          {
            "type": "patchouli:text",
            "text": "dict.nffgirls.desc.mob.alraune"
          }
        ]
      }

   b. Add translation keys to lang/en_us.json:
      "dict.nffgirls.desc.mob.alraune": "[content from alraune.txt]"

   c. Add translation keys to lang/zh_cn.json:
      "dict.nffgirls.desc.mob.alraune": "[content from alraune.txt in Chinese]"

   d. Create Chinese Patchouli entry:
      patchouli_books/mob_dictionary/zh_cn/entries/mob/alraune.json
      (same structure as English)

   e. Ensure friending entries exist:
      patchouli_books/mob_dictionary/zh_cn/entries/friending/alraune.json
      (copy from en_us version)

2. Use the content from:
   - EN_US_BOOK_CONTENT.txt for English descriptions
   - ZH_CN_BOOK_CONTENT.txt for Chinese translations
   - ROOT_JSON_CONTENT.txt for entity rendering parameters
